# Checkout Page Design - Static UI

## Descripción

Página estática que muestra el diseño visual de un proceso de checkout para e-commerce. Incluye formulario de información de contacto, dirección de envío y resumen de productos con cálculo de totales.

## Características del Diseño

### Formulario de Checkout
- **Contact Information**: Campos para email y teléfono
- **Shipping Address**: Formulario completo de dirección
- **Save Information**: Checkbox para guardar datos

### Resumen de Pedido
- **Producto**: Vintage Backpack
- **Precio Original**: $94.99
- **Precio de Venta**: $54.99
- **Cantidad**: 2 unidades
- **Shipping**: $19.00
- **Total**: $148.98
